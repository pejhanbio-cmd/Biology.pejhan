# acadmyBIOLOGY

آموزش رایگان زیست‌شناسی و سلامت و بهداشت برای دانش‌آموزان پایه‌های دهم، یازدهم و دوازدهم.

## درباره پروژه

- **موضوع:** آموزش زیست‌شناسی و سلامت و بهداشت
- **مخاطبان:** دانش‌آموزان پایه‌های دهم، یازدهم و دوازدهم
- **هزینه استفاده:** کاملاً رایگان
- **زبان:** فارسی (RTL)
- **فناوری:** React + Vite
- **میزبانی:** GitHub Pages

## بخش‌های آموزشی

- **زیست‌شناسی دهم** — ۷ فصل
- **زیست‌شناسی یازدهم** — ۹ فصل
- **زیست‌شناسی دوازدهم** — ۸ فصل
- **سلامت و بهداشت دوازدهم** — ۱۴ درس

## امکانات

- طراحی مدرن، علمی و دانش‌آموزپسند
- حالت روشن (Light Mode) و تاریک (Dark Mode)
- کاملاً واکنش‌گرا (موبایل، تبلت، کامپیوتر)
- محتوای فصل‌محور برای زیست‌شناسی
- هر درس سلامت و بهداشت در صفحه اختصاصی

## نحوه افزودن محتوا

تمام محتوای آموزشی در فایل `src/data/content.js` قرار دارد.

برای افزودن متن هر گفتار یا درس:

1. فایل `src/data/content.js` را باز کنید.
2. به دنبال بخش مورد نظر بگردید.
3. مقدار `text: ''` را با متن خود جایگزین کنید.

مثال:

```js
{ 
  id: '1-1', 
  title: 'گفتار ۱: زیست‌شناسی چیست؟', 
  text: '<p>متن آموزشی شما اینجا قرار می‌گیرد.</p>' 
}
